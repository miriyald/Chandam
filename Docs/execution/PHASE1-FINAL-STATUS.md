## Known Limitations

### Docker Build Issue (RESOLVED ✅)
**Status**: FIXED - Using prebuilt binaries approach

**Solution**:
- Removed multi-targeting (net8.0 only, no backward compatibility needed)
- Build locally: `dotnet publish -c Release -o publish/chandam-api`
- Dockerfile.simple copies prebuilt files
- Docker image builds and runs successfully
- Rules load correctly from JSON files (14 + 379 rules)

### Windows Bash/Curl Encoding Issue (RESOLVED ✅)
**Status**: FIXED - Proper encoding method identified

**Problem**: Using `curl -d '{...}'` directly with Telugu Unicode text on Windows bash mangled characters and newlines, causing "Index was outside the bounds of the array" errors

**Root Cause**: Windows bash + curl combination doesn't preserve UTF-8 encoding properly when passing Telugu text in command-line arguments

**Solution**: Use stdin pipe pattern `echo '{}' | curl -d @-` to preserve proper encoding

**Before** (failed):
```bash
curl -d '{"poemText":"తెలుగు...","language":0}'  # ❌ Encoding issues
```

**After** (works):
```bash
echo '{"poemText":"తెలుగు...","language":0}' | curl -d @-  # ✅ Proper UTF-8
```
