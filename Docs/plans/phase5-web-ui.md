# Plan: Chandam Web UI - Vite + TypeScript with WASM Backend

## Context

The current Blazor WASM app (`Chandam.Wasm`) works but uses Blazor's full rendering pipeline. The user wants a **better, mobile-friendly web interface** built with TypeScript/HTML/CSS that calls into the same C# WASM engine for all computations. No API server. The original website serves as functional reference but the new UI should be modern, clean, and mobile-first.

**Key decisions:**
- Blazor stays as WASM host (bootstrapping + rule loading)
- **Vite + TypeScript** for compiled, type-safe frontend code
- TS source in `Chandam.Wasm/Client/`, build output to `wwwroot/`
- **Multi-page routing** with clean URLs via `history.pushState` + 404 fallback
- Consistent **header/footer** across all pages, content loaded via `fetch()`
- Collapsible accordion sections for mobile-friendliness
- **Unicode/emoji icons only** - no icon libraries
- Design: Black/White with Red/Green accents, Noto Sans Telugu

---

## Architecture

```
Blazor WASM boots -> Loads rules from JSON -> Exposes [JSInvokable] C# methods
     |
TS Router intercepts navigation -> loads page content via fetch() or activates TS modules
     |
Vite builds TS -> JS bundle in wwwroot/js/
index.html has persistent header/footer, <main> swaps content
```

### Page Routing

Clean URLs via `history.pushState()`. Direct URL access via `404.html` fallback (copies to index.html for GitHub Pages).

| Route | Content | Type |
|-------|---------|------|
| `/` or `/home` | Welcome/intro | Static HTML fragment (fetch) |
| `/analyze` | Main editor tool | TS-driven interactive page |
| `/about` | Chandam/prosody explanation | Static HTML fragment (fetch) |
| `/credits` | Acknowledgments | Static HTML fragment (fetch) |
| `/contact` | Feedback/contact info | Static HTML fragment (fetch) |

**Only `/analyze` is fully built. All others are placeholder shells.**

## Step 2: Router (`Client/src/router.ts`)

Simple client-side router (~40 lines):

```typescript
type Route = { path: string; handler: () => void | Promise<void> };

const routes: Route[] = [
  { path: '/',        handler: () => loadPage('pages/home.html') },
  { path: '/home',    handler: () => loadPage('pages/home.html') },
  { path: '/analyze', handler: () => activateAnalyze() },
  { path: '/about',   handler: () => loadPage('pages/about.html') },
  { path: '/credits', handler: () => loadPage('pages/credits.html') },
  { path: '/contact', handler: () => loadPage('pages/contact.html') },
];

// loadPage(url) -> fetch HTML fragment -> inject into <main id="content">
// activateAnalyze() -> render editor UI via TS, wire up WASM calls
// Nav links use click handler: history.pushState + route()
// window.onpopstate = route (back/forward)
```

## Step 5: TypeScript Types (`Client/src/types.ts`)

```typescript
interface RuleSummary {
  identifier: string; name: string;
  padyamType: string; padyamSubType: string;
  frequency: string; lines: number;
}
interface ChandamMatch {
  identifier: string; name: string; matchPercentage: number;
  padyamType: string; description: string; details: MatchDetails;
}
interface MatchDetails {
  lineCount: number; matchedLines: number;
  yatiMatched: boolean; prasaMatched: boolean; mismatches: string[];
}
interface DetermineResponse { success: boolean; matches: ChandamMatch[]; errorMessage?: string; }
interface TryMatchResponse { isMatch: boolean; match: ChandamMatch; errorMessage?: string; }
interface ScoresResponse { scores: ChandamScore[]; totalRulesEvaluated: number; errorMessage?: string; }
interface RuleInfoResponse { /* all rule fields + examples */ }
```

## Step 6: WASM Bridge (`Client/src/wasm-bridge.ts`)

Type-safe wrappers calling `DotNet.invokeMethodAsync('Chandam.Wasm', ...)`.
Each method returns parsed JSON (C# returns string, TS parses).

## Step 7: C# JSInvokable Bridge (`Chandam.Wasm/JsBridge.cs`)

```csharp
[JSInvokable] public static string GetAllRules()       // -> RuleSummary[] JSON
[JSInvokable] public static string Determine(...)       // -> DetermineResponse JSON
[JSInvokable] public static string TryMatch(...)        // -> TryMatchResponse JSON
[JSInvokable] public static string GetScores(...)       // -> ScoresResponse JSON
[JSInvokable] public static string GetRuleInfo(...)     // -> RuleInfoResponse JSON
[JSInvokable] public static string GetRandomPoem()      // -> poem text string
```

**Reuses (no business logic changes):**
- `ChandamService` - Chandam.API/Services/ChandamService.cs
- `RuleLoaderService` - Chandam.API/Services/RuleLoaderService.cs
- `DescriptionBuilder` - Chandam.API/Services/DescriptionBuilder.cs

## Build & Verification

```bash

cd Chandam.Wasm/Client && npm install && npm run build

# Build WASM
cd ../.. && dotnet publish Chandam.Wasm -c Release -p:ExcludeYaml=true
```
